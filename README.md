# Portfólio

Profissional de IT com foco em **automação de processos**, **Microsoft Power Platform**
e **gestão de infraestrutura Windows**.

Abaixo estão os projetos com código e documentação técnica públicos.

## Projetos

### [Power Automate — Sistema de Pedidos de Crédito](https://github.com/xanscr/power-automate-credit-request-system)

Orquestração do ciclo de vida de pedidos de crédito com Power Automate, SharePoint Online e
Power Automate Approvals. Inclui documentação funcional de 8 fluxos, código-fonte extraído do
Power Automate e comparação entre ambientes de teste e produção.

`Power Automate` · `SharePoint` · `Microsoft 365` · `Workflow Automation` · `Documentação técnica`

### [Windows — Instalação Automatizada (Unattend)](https://github.com/xanscr/windows-unattended-deployment)

Deployment não assistido de estações Windows com `autounattend.xml`, scripts PowerShell de
especialização, instalação de software e configuração de primeiro logon.

`Windows` · `PowerShell` · `Autounattend` · `Deployment` · `Sysadmin`

### [Manual de Preparação de Equipamentos (IT)](https://github.com/xanscr/it-equipment-preparation-manual)

Procedimento genérico para preparação, configuração e entrega de equipamentos a colaboradores,
com placeholders para adaptação a qualquer organização.

`IT Support` · `Documentação` · `Processos` · `Onboarding`

### [YouTube Music — Custom Filters](https://github.com/xanscr/ytmusic-custom-filters)

Filtros documentados para remover elementos da interface do YouTube Music em
ReVanced/Morphe (Android) e uBlock Origin (Web).

`ReVanced` · `uBlock Origin` · `Android`
